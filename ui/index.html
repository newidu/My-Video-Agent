COMPATIBILITY

Provider support

● Supported through compatible API

DeepSeek, OpenAI, OpenRouter, Groq, Together, Fireworks, Mistral, xAI, Gemini-compatible, DeepInfra, Cerebras, SambaNova, NVIDIA NIM, Hugging Face, Ollama, LM Studio, vLLM and custom endpoints.

○ Native adapter planned

Anthropic Messages API, AWS Bedrock, Google Vertex AI and Azure-specific authentication need provider-native request/auth adapters. They are not presented as working until implemented.

Video, image and speech-generation services

This build connects text/agent models only. It does not yet have configurable third-party video generation, image generation, transcription or text-to-speech API adapters. Video compositions are rendered by the built-in canvas editor; music and beat synthesis use the existing local audio engine.
